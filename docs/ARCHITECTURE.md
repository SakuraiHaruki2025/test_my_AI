# アーキテクチャドキュメント

## プロジェクト概要

このプロジェクトは、日本語LLMを学習・使用するための教育的なフレームワークです。
最新のLLM技術（2024年時点）を採用し、限られたハードウェアリソースでも動作するよう設計されています。

## 技術スタック

### コアライブラリ
- **PyTorch**: 深層学習フレームワーク
- **Transformers**: Hugging Faceのトランスフォーマーライブラリ
- **PEFT**: Parameter-Efficient Fine-Tuning（LoRA/QLoRA）
- **bitsandbytes**: 量子化ライブラリ

### 最新技術の採用

1. **QLoRA (Quantized LoRA)**: 2023年発表、メモリ効率的なファインチューニング
2. **4bit/8bit量子化**: LLM.int8()技術を使用
3. **LoRA**: 低ランク適応による効率的な学習
4. **混合精度学習**: fp16で高速化

## 3つのAIモデル

### 1. 敬語AI - 学習済みモデル
- ベース: rinna/japanese-gpt-neox-3.6b
- 特徴: 丁寧な敬語表現
- 学習: 不要（事前学習済み）

### 2. 関西弁AI - カスタム学習
- ベース: rinna/japanese-gpt-neox-3.6b
- 特徴: 関西弁の会話
- 学習: QLoRAでファインチューニング

### 3. 形容詞＋やねAI - カスタム学習
- ベース: rinna/japanese-gpt-neox-3.6b
- 特徴: 形容詞＋「やね」パターン
- 学習: QLoRAでファインチューニング

## メモリ最適化戦略

### 推論時
- 8bit量子化: メモリ使用量50%削減
- 4bit量子化: メモリ使用量75%削減
- 自動デバイス配置

### 学習時
- QLoRA: 4bit量子化 + LoRA
- 勾配累積: 実効バッチサイズ拡大
- グラディエントチェックポイント
- ページドオプティマイザ

## パフォーマンス目安

### 推論（rinna 3.6B）
- FP16: ~8GB VRAM
- 8bit: ~4GB VRAM
- 4bit: ~2.5GB VRAM

### 学習（rinna 3.6B + QLoRA）
- バッチサイズ4: ~12GB VRAM
- RTX 4070 SUPERで快適に動作

## 拡張性

- 新しいモデルの追加が容易
- 異なるベースモデルの使用可能
- カスタムプロンプトテンプレート対応
